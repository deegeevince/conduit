# A cycle that keeps going

summary: A loop, a cycle that repeats, something that comes back to where it began: the water cycle, a life cycle, the seasons, a feedback loop.
reason: only if you are drawing something that repeats in a loop

Draws a repeating process as a ring of stages, with a marker that goes round.

**Use it when** the last stage leads back to the first: a natural cycle, a life cycle, a feedback loop.

**Not when** it happens once and ends: that is a flow.

**Example**
```series
scene caption calm
cycle year | The year of an oak
node bud | Buds open
node leaf | Leaves feed the tree
node acorn fill=accent | Acorns fall
node bare | Bare, resting
say | Nothing in it is a beginning.
```

**What failed** Arrows drawn by hand as curves: the loop did not close, and the labels sat beside the wrong arrow. Naming the stages as nodes of a cycle closes the ring by construction.
