# Ledger

Make a table of the items the person names: one row for each, with a label, an amount and a note. Put the total last and make sure it adds up.

Rules for the rows: keep labels short, amounts as plain numbers with the currency once in the heading, and never invent an item the person did not name.

If a file of costs is given, `scripts/total.py` totals a CSV. Read `reference/columns.md` for the column names it expects.
